Hi Angela,

For image compression, I recommend using this local Windows workflow as the main option:

https://saiaf25.github.io/lifeusa/technical-seo-fixes/windows-image-compression-workflow/

This is the best regular workflow because you can keep a folder of blog images on your computer, run one batch file, and get WebP copies in an output folder. It is useful when you have several images for a blog post and want a repeatable process instead of uploading images one by one to an online tool.

Other options if you only need a quick one-time compression:

TinyPNG:
https://tinypng.com/

Good for quick browser-based compression without installing anything.

Squoosh:
https://squoosh.app/

Good when you want to preview one image and manually adjust compression quality before saving.

For regular weekly blog publishing, I would use the Windows workflow first. Then use TinyPNG or Squoosh only when you need a quick backup option.
