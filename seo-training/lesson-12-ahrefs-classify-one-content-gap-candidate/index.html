Classify one Content Gap candidate

A ranking gap is not automatically a missing-content gap. LifeUSA may already have a page for the same search need.

10–15 minutesSEO beginnerOne candidate card
AhrefsKeyword and competitor estimates
By the end: you can classify one Content Gap row as an existing-page opportunity, possible new topic, rejection, or unknown without approving content.

Gap first, ownership second

Ranking gap

A comparison site ranks for the keyword while the target does not in Ahrefs’ data.

Content owner

The existing LifeUSA page responsible for that search intent, confirmed through the content map or Saiaf.

No ranking does not mean no page. Check existing ownership before suggesting another URL that could duplicate the same intent.

NOW USE A LIFEUSA WORKFLOW

Classify one row without approving it

Use only target and comparison domains approved for the LifeUSA exercise.

  1. Open Competitive Analysis, select Keywords, and enter lifeusa.org as the target.
  2. Enter the approved comparison domains and select Show keyword opportunities.
  3. Set United States. Narrow to the approved topic and exclude branded comparison phrases or topics LifeUSA cannot accurately serve.
  4. Choose one relevant non-branded row. Inspect each comparison site’s ranking page.
  5. Use the provided LifeUSA content map or Saiaf’s confirmation to record the existing owner. If you cannot confirm it, write Unknown.
  6. Classify the row: Improve existing, Possible new, Reject, or Unknown. Save it as Candidate only; not approved.
Do not create, rewrite, or publish content. If ownership evidence is missing, preserve “Unknown” instead of turning uncertainty into a new-page recommendation.

Explain what a Content Gap does not prove

“Content Gap means comparison sites rank and the target does not. It does not prove ___.”

  • I used approved target and comparison domains.
  • I excluded branded or unsuitable topics.
  • I checked for an existing LifeUSA owner.
  • I saved a candidate classification, not approval.
