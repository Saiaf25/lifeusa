Segment, compare, and export safely

Use after Lessons 5–8. This card preserves the report context and the difference between observation and cause.

The four-step check

  1. Confirm: exact property, report, search type, dates, and old filters.
  2. Segment: use one query or device filter; preserve the rest of the scope.
  3. Compare: describe the displayed difference before asking why it exists.
  4. Export: confirm the table grouping, use a descriptive filename, and attach the review question.

Boundaries to remember

  • A query group is not a visitor identity.
  • A device difference is not a diagnosis.
  • The Difference column does not establish cause.
  • A direct export is not a complete raw dataset.
When uncertain: preserve the exact source, label the unknown, and bring the question to Saiaf before any live action.
