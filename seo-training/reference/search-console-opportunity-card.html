Choose one page to improve

Use this card after the lesson. It is a memory aid, not a replacement for making the decision yourself.

The four-step check

  1. Look: Performance → Search results → Last 3 months → Pages.
  2. Notice: meaningful impressions, position roughly 4–15, and weak CTR beside similar pages.
  3. Inspect: click the page → Queries → choose one query that matches the page.
  4. Explain: write one sentence using the evidence and propose one test.

What the numbers mean

ImpressionsGoogle showed the page.
CTRViews that became clicks.
PositionApproximate average ranking.
Best beginner opportunity: the page is already visible and reasonably close to page one, but not enough searchers click it.

Stop and ask for help when

  • You cannot access the exact lifeusa.org property.
  • The query does not match the page’s purpose.
  • The page has almost no impressions.
  • The average position is far beyond page two.
  • You are considering a live edit, redirect, deletion, or indexing request.
