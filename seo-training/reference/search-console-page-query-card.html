Connect a page to its search query

Use this after Lesson 2 when you need to explain what searchers expect from one page.

The five-step check

  1. Open Performance → Search results.
  2. Choose one row in Pages so the page filter appears.
  3. Open Queries and sort by impressions.
  4. Choose one relevant, non-branded query.
  5. Explain why the search wording matches the page purpose.
Question and answer: the query is the searcher’s question; the page is Google’s proposed answer.
Do not invent missing queries. Some queries are omitted for privacy, so table totals may not match chart totals.

Your one-sentence pattern

“People searched for ___, and Google showed ___. The match is useful because ___. The page may still need to answer ___.”
