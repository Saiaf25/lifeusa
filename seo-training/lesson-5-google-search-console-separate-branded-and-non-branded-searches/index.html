LESSON 5 · Google Search Console

Separate branded from non-branded searches

Branded searches include a LifeUSA name. Non-branded searches reveal broader discovery, but they do not prove the searcher is new.

10–15 minutesSEO beginnerOne discovery card
Google Search ConsoleFirst-party search evidence
By the end: you can compare branded and non-branded visibility for one page and describe the difference without calling the groups new versus returning visitors.

Two query groups, one careful distinction

Branded

The query includes LifeUSA’s name, domain, or a recognized brand variation.

Non-branded

The query does not include the brand and often describes a need, question, or topic.

Use the filter to discuss discovery, not people. Query groups do not identify whether a searcher is new or returning, and Google says a classification can be wrong.
Official sources:
  • Google: Performance report common tasks
  • Google: Query dimensions and branded-filter limits

NOW USE A LIFEUSA WORKFLOW

Compare the two groups for one page

Reuse the LifeUSA page from Lessons 1–4. This is observation only; do not change the page.

  1. Open the exact lifeusa.org property, then open Performance → Search results.
  2. Set Search type: Web and Date: Last 3 months. Keep the page filter from the earlier lessons.
  3. Remove any device or date comparison. Add Query → Branded and record total clicks and impressions.
  4. Change the same query filter to Non-branded and record total clicks and impressions.
  5. Compare impressions first, then clicks. Write one observation that describes the report without describing the people behind it.
If the branded filter is missing, stop. It may be unavailable for a sub-property or a property with low impressions. Record the block; do not present a manual “contains LifeUSA” filter as equivalent.
