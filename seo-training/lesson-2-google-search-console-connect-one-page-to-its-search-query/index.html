Connect one page to the query behind it

Lesson 1 found a page with an opportunity. Now you will discover the exact search wording that gives that opportunity meaning.

Page first, query second

Choose one page→Filter the report→Read its queries
A page is the answer

The URL contains the content Google showed to a searcher.

A query is the question

The words describe what the searcher was trying to find.

Your decision: choose a query with meaningful impressions whose wording clearly matches the page’s main purpose.

Primary sources: Google defines queries and pages in Dimensions and data groupings and explains how to view pages for a query in Performance report common tasks.

NOW USE LIFEUSA DATA

Find the query behind your Lesson 1 page

Use the same page you selected in Lesson 1. If you do not have that card, complete Lesson 1 before continuing.

  1. Open the exact lifeusa.org property in Search Console.
  2. Open Performance → Search results and set the date to Last 3 months.
  3. Open Pages and click the page from your Lesson 1 card. Confirm that a page filter appears above the chart.
  4. Open Queries. Sort by Impressions from highest to lowest.
  5. Skip the organization name for this exercise. Choose one non-branded query that accurately describes what the page should answer.
  6. Record the query and its numbers below. Do not change the page yet.
Do not expect every query to appear. Google omits some queries for privacy, so the table can be smaller than the chart totals.
