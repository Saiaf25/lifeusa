LESSON 6 · Google Search Console

Compare mobile and desktop click-through rate

A device comparison can show where clicking differs. It cannot explain why the difference exists.

10–15 minutesSEO beginnerOne device check
By the end: you can compare mobile and desktop CTR for the same page and flag a difference for review without claiming the device caused it.

Compare like with like

Same scope

Keep the same property, page, search type, and date range for both devices.

Observation only

CTR describes clicking. It does not reveal user feelings, page quality, or the cause of a difference.

Read CTR and total clicks separately. A device can have lower CTR yet still produce more clicks because it had many more impressions.
Official sources:
  • Google: Advanced filtering and device comparisons
  • Google: Performance dimensions and data groupings

What is the safest conclusion?

Practice data only: Mobile has 480 clicks, 24,000 impressions, and 2.0% CTR. Desktop has 200 clicks, 4,000 impressions, and 5.0% CTR.

NOW USE A LIFEUSA WORKFLOW

Run one device comparison

Use the same LifeUSA page and Last 3 months date range from Lesson 5.

  1. Open Performance → Search results in the exact lifeusa.org property.
  2. Keep Search type: Web, Date: Last 3 months, and the same page filter.
  3. Remove any existing comparison. Search Console permits only one comparison at a time.
  4. Turn on Clicks, Impressions, and Average CTR.
  5. Add Device → Compare → Mobile versus Desktop. Record clicks, impressions, and CTR for both.
  6. State whether mobile CTR is lower, higher, or similar. Add one question to investigate later; do not diagnose a cause.
If a device shows “~”, write “Not enough data shown.” Do not turn an unavailable value into a measured zero.

Separate observation from diagnosis

  • I kept the scope identical for both devices.
  • I recorded clicks, impressions, and CTR.
  • I distinguished CTR from total clicks.
  • I wrote a question, not a diagnosis.
