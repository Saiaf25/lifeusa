LESSON 7 · Google Search Console

Find the page behind a click change

Sitewide clicks can rise or fall for many reasons. The Pages table helps you find where the visible movement occurred.

10–15 minutesSEO beginnerOne triage note
By the end: you can compare equal periods, sort the Pages table by Clicks Difference, and select one displayed page for review without claiming why it changed.

Movement first, explanation later

Difference

The recent-period value minus the previous-period value for a displayed row.

Cause

The reason for the movement. Search Console’s Difference column does not supply it.

Sort in the direction of the sitewide movement. For a decline, inspect the most negative differences; for a gain, inspect the most positive.
Official sources:
  • Google: Performance report common tasks
  • Google: Comparisons and the Difference column

NOW USE A LIFEUSA WORKFLOW

Trace one sitewide movement to a page

Start without a page, query, or device filter so you can see the property-level direction first.

  1. Open the exact lifeusa.org property and Performance → Search results.
  2. Clear page, query, and device filters. Set Date → Compare → Last 28 days to previous period.
  3. Turn on Clicks and Impressions. Read whether total site clicks rose or fell.
  4. Open the Pages tab. Sort Clicks Difference most negative first for a decline or most positive first for a gain.
  5. Choose one displayed page with a meaningful movement. Record its recent and previous clicks and impressions.
  6. Write what changed. Leave the reason unknown until another source supports it.
Use complete periods. Do not substitute current-day preliminary data, and do not attribute a change to an event, update, title, or campaign without supporting evidence.

PASS CHECK · RETRIEVE, DON’T REREAD

Recall what Difference can and cannot do

“The Difference column tells me ___. It does not tell me ___. For a decline, I sort toward ___. For a gain, I sort toward ___.”

  • I cleared old filters before reading the sitewide direction.
  • I used equal, complete date ranges.
  • I sorted in the same direction as the movement.
  • I did not turn a change into a cause.

If the comparison or sort is blocked, ask Saiaf. Include the property, ranges, active filters, and the exact column you expected to see.
