LESSON 13 · Codex

Write a safe, specific SEO prompt

Codex works best when the requested result, supplied evidence, output shape, and stopping boundaries are clear.

10–15 minutesSEO beginnerOne prompt card
By the end: you can decide what Codex should produce, what evidence it may use, and what it must not do.

Four useful prompt parts

Goal

The result you want Codex to produce.

Context

The relevant source material and facts that can change the result.

Output

The format, length, audience, or sections you need.

Boundaries

What must stay unchanged and which actions or assumptions are prohibited.

Codex output is not SEO evidence. The Search Console or Ahrefs artifact remains the source; Codex helps organize and question it.

COPYABLE EXAMPLE · PRACTICE OR ADAPT

Practice prompt — replace the practice-only figures with an approved card

GOAL
Turn this Search Console opportunity card into one short content-improvement brief for our Wednesday review.

CONTEXT
Page: https://www.lifeusa.org/example-page
Query: donate to orphans
Search Console evidence: 2,400 impressions, 1.1% CTR, average position 8.6
These are practice-only numbers.

OUTPUT
Return four short sections: Evidence, Interpretation, Test, and Missing information.

BOUNDARIES
Use only the supplied card. Do not invent causes, opinions, or figures.
Do not browse, edit the website, send, or publish anything.
  1. Open a new Codex task and complete the simulated quiz before submitting anything.
  2. Write the Goal: one result for the Wednesday review.
  3. Add Context: name and paste the approved source, including its property, date, page, and metrics.
  4. Define the Output: short sections, audience, and length.
  5. Add Boundaries: use only the supplied source; flag missing information; do not browse, edit, send, or publish.
  6. Submit the prompt and save the filled prompt card. Do not act on the recommendation yet.
Do not attach private or sensitive material that is unnecessary for the task. Use only the approved SEO artifact and keep the task in review-only scope.
