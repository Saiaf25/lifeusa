LESSON 3 · GOOGLE SEARCH CONSOLE

Compare two equal periods before judging change

A single number has no direction. You need a fair before-and-after comparison to say whether search performance moved.

10–15 minutesBeginnerOne trend statement
By the end: you can compare the last 28 complete days with the previous 28 days and write one careful conclusion from clicks and impressions.

NOW USE LIFEUSA DATA

Compare one page fairly

Use the same page you investigated in Lessons 1 and 2. Keeping the page fixed makes the new time skill easier to learn.

  1. Open Performance → Search results in the exact lifeusa.org property.
  2. Add or confirm the filter for your chosen page.
  3. Open the Date filter, choose Compare, then select Compare last 28 days to previous period.
  4. Turn on Clicks and Impressions. Leave average position aside for this first comparison.
  5. Read the totals for both periods. Check whether clicks and impressions moved in the same direction.
  6. Write one conclusion using “rose,” “fell,” or “stayed similar.” Add one context note if a campaign or seasonal event may have influenced demand.
Avoid partial-day comparisons. Search Console normally uses complete days, and the newest data may still be preliminary.

PASS CHECK

Report the trend without overstating it

“Compared with the previous 28 days, clicks ___ from ___ to ___, while impressions ___ from ___ to ___. This shows ___. It does not yet prove ___.”

  • I compared equal periods for the same page.
  • I used clicks and impressions before interpreting position.
  • I described the change without claiming a cause.
  • I noted any known campaign or seasonal context.

If the two metrics move in opposite directions, ask Saiaf or Codex before deciding what it means. Include both periods and all four totals.
