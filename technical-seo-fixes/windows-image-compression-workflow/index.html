Windows Image to WebP Workflow

A simple Windows folder workflow for converting blog images into WebP files before uploading them to the LifeUSA website.

Version 1.0 July 8, 2026 Prepared by Saiaf Gamal For Angela Joyce
Overview Install Script Use Troubleshooting Sources

Overview

This method uses ImageMagick on Windows. After it is installed once, you can place a small .bat file inside any folder of images, double-click it, and it will create WebP copies in a new folder called output.

What it does

Converts common image files such as PNG, JPG, JPEG, BMP, TIFF, and GIF into WebP files.

What it does not do

It does not delete, overwrite, or rename the original images. The simple script also does not guarantee that every image will be under 80 KB.

Recommended habit: keep the original images in one folder, use the WebP files from output for upload, and only delete originals after the blog is fully published and checked.

One-Time Setup on Windows

  1. Download ImageMagick for Windows. Open the official download page: https://imagemagick.org/download/. Scroll to the Windows Binary Release section and download the recommended 64-bit Windows installer.
  2. Install it normally. During installation, if Windows shows an option to add ImageMagick to the system path, keep that option selected. This lets the magick command work from a batch file.
  3. Check that it works. Open Command Prompt, type the command below, and press Enter: 
    magick -version
    If Windows prints ImageMagick version information, the setup is ready.
Alternative install option: if you already use Windows Package Manager, ImageMagick also lists this command: winget install ImageMagick.Q16-HDRI.

Create the Batch File

  1. Open Notepad on Windows.
  2. Choose one of the scripts below and copy it into the empty Notepad file.
  3. Save it as Convert_to_webp.bat.
  4. Place the file inside the same folder as the images you want to convert.

Simple conversion script

This version keeps the image dimensions as they are and converts each image to WebP. It is useful for format conversion, but it does not intentionally target 80 KB.

@echo off
set output_folder="output"

rem Create the output folder if it does not exist
if not exist %output_folder% (
    mkdir %output_folder%
)

rem Convert all image files to WEBP format and save in the output folder
for %%f in (*.png *.jpg *.jpeg *.bmp *.tiff *.gif) do (
    magick "%%f" "%output_folder%\%%~nf.webp"
)

echo All image files have been converted to WEBP and saved in %output_folder%.
pause
Answer to the 80 KB question: this simple script does not guarantee a good image under 80 KB. It keeps the original dimensions and lets ImageMagick use its normal WebP settings, so a large or detailed image may still be much larger than 80 KB.

Recommended blog version

This version is better for general website uploads because it also limits very large images to a maximum of 1600 pixels wide or high and uses a practical WebP quality level. It usually gives a good balance, but it is still not a hard 80 KB target.

@echo off
set output_folder="output"

rem Create the output folder if it does not exist
if not exist %output_folder% (
    mkdir %output_folder%
)

rem Convert common image files to WEBP, auto-rotate, resize oversized images, and save in output
for %%f in (*.png *.jpg *.jpeg *.bmp *.tiff *.gif) do (
    magick "%%f" -auto-orient -resize "1600x1600>" -quality 75 "%output_folder%\%%~nf.webp"
)

echo All image files have been converted to WEBP and saved in %output_folder%.
pause

80 KB target version

Use this version when the goal is to keep blog images near or under 80 KB. It resizes oversized images, asks WebP to target about 80,000 bytes, and uses a slower compression method for better results.

@echo off
set output_folder="output"

rem Create the output folder if it does not exist
if not exist %output_folder% (
    mkdir %output_folder%
)

rem Convert images to WEBP and try to keep each output near 80 KB
for %%f in (*.png *.jpg *.jpeg *.bmp *.tiff *.gif) do (
    magick "%%f" -auto-orient -resize "1200x1200>" -define webp:target-size=80000 -define webp:method=6 "%output_folder%\%%~nf.webp"
)

echo Images have been converted to WEBP. Check the output folder and preview quality before uploading.
pause
Best practical rule: use the 80 KB target version first, then open the output folder and preview the images. If a donor-facing photo looks too soft, use the recommended blog version instead and accept a slightly larger file.
Important: if the saved file becomes Convert_to_webp.bat.txt, Windows will treat it as a text file instead of a script. In File Explorer, turn on file name extensions and make sure the file ends with .bat.

How To Use It Each Time

  1. Create a folder for the blog images, for example Friday Blog Images.
  2. Put all the images for that blog post in the folder.
  3. Place Convert_to_webp.bat inside that same folder.
  4. Double-click Convert_to_webp.bat.
  5. Wait until the black Command Prompt window says the images have been converted.
  6. Open the new output folder.
  7. Upload the WebP files from output to Wix or the website editor.

Before upload

Open a few WebP files and make sure they look normal. Pay attention to faces, text in images, logos, and maps.

After upload

Preview the blog page and confirm that the images load correctly on desktop and mobile.

Troubleshooting

Problem What to do
Double-clicking the file opens Notepad. The file was probably saved as .bat.txt. Rename it so it ends with .bat.
The window says magick is not recognized. ImageMagick is not installed correctly, or it was not added to the system path. Reinstall ImageMagick and keep the path option selected.
No output folder appears. Make sure the batch file is inside the same folder as the images and that the image extensions are PNG, JPG, JPEG, BMP, TIFF, or GIF.
The image is still too large. Use the recommended blog version of the script. If needed, lower -quality 75 to -quality 65 and run it again from the original images.
The image looks blurry or poor. Use a higher quality number such as -quality 82, or keep the image larger if it is a detailed donor-facing photo.
